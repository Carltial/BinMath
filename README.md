# BinMath v2.0 for Windows x64

BinMath is a modular program for all kinds of mathematical operations. \nAS you will see, you can even customise it by adding your own functions.

The aim of BinMath is to meet whatever your needs may be.

It was designed as a system with a user-friendly CLI interface for \nperforming repetitive arithmetic operations. It is not a calculator with \npre-installed programmes, but rather an engine that allows you to add the functionality you need, specifically developed for the problem at hand.

This means it is no longer limited to solving mathematical problems, but can extend to other fields.

## Command Levels Structure
This programme is designed to support commands according to the level. If you try to enter a command at the wrong level, it may not be executed.

Its main functions are:

```[C]
1) exit			--> quit the programme
2) help			--> check manual
3) cls/clear		--> clear screen
4) break/brk		--> break current menu while
5) addApp/aap		--> Add a new function to the programme
6) appMenu/amu		--> Go to the installed functions
```
## Expansion

As it was said before, BinMath is not limited to its pre-included functions. Yo can expand with whatever new function you wish.

BinMath v2.0 for Windows x64 works with DLLs. In fact, its pre-included functions are DLLs.

You can add your own DLL as long as its function is named runPoint. 

Whatever you wish to do, you can do it.
